# 图像生成定价保护

## 行为

处理 `/v1/images/generations` 请求时，系统在选择渠道、估算令牌、预扣费和调用上游之前检查原始模型是否配置了图像倍率。

如果模型不存在有效的图像倍率配置，请求立即返回错误：

- HTTP 状态码为 `200`。
- 错误码使用 `invalid_request` 语义。
- 错误信息为 `image generation is currently not supported`。
- 标记为不可重试，不会调用上游，也不会进入计费流程。

HTTP 200 是当前二开保留的客户端兼容契约；调用方必须检查响应中的 `error`，不能只判断 HTTP 状态。

## 范围

该保护只针对图像生成模式，不包含图像编辑。它检查原始模型名，避免模型映射后绕过定价边界。

配置好对应模型的图像倍率后，请求自动恢复正常路径，不需要迁移已有数据。

## 关键实现

- `controller/relay.go`：请求早期保护。
- `setting/ratio_setting`：图像倍率查询。

## 验证重点

验证未定价模型返回 HTTP 200 错误体、不会产生上游调用或扣费；再验证配置图像倍率后请求能继续进入原有图像中继流程。
