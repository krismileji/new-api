# 图像生成定价保护

`/v1/images/generations` 请求在选择渠道、估算用量、预扣费和调用上游前检查原始模型是否配置有效图像倍率。

## 检查时机

检查发生在渠道选择和预扣费之前，只覆盖图像生成，不包含图像编辑。检查使用客户端请求的原始模型名，配置模型映射不能绕过该限制。

## 失败响应

未配置倍率时立即返回：

- HTTP 状态码 `200`
- 错误码 `invalid_request`
- 消息 `image generation is currently not supported`
- 不重试或切换到其他渠道

该路径不调用上游、不预扣费、不写入渠道成本，也不占用渠道并发租约。

## 恢复

在系统设置中为该原始模型配置图像倍率后，请求恢复原有图像中继路径。已配置倍率为 `0` 仍视为已配置；只有映射中不存在该模型时才触发保护。
