# 渠道探测策略与业务周期监测

## 使用方式

在“渠道监控 → 渠道配置”的渠道行打开“探测策略”：

1. 开启“禁止自动探测”。状态、分组、智能调度采样/恢复、健康检查和模型检测的自动任务会跳过该物理渠道；手动检测仍实际请求上游。
2. 可另行开启“小输入请求返回自定义内容”，填写阈值和文本。两个开关默认关闭；恢复自动探测会同时关闭小输入响应，并保留阈值与文本草稿。
3. 在状态监测或分组监控中开启周期监测并配置模型、周期。禁探测成员使用 Redis 业务数据，普通成员保留实际探测。

阈值为**严格小于**，1k = 1000 tokens，最多 3 位小数，范围 1～1,000,000 tokens；响应最多 16,384 个 Unicode 字符。估算使用请求模型的本地 tokenizer，对完整文本上下文 JSON 计数，包含系统提示、历史消息、工具定义和结构。它与供应商计费 token 数可能不同，不受全局关闭计费 token 统计影响。

支持 Chat Completions、Responses、Claude Messages、Gemini 文本协议的流式及非流式响应。服务端引用上下文、多模态、强制工具调用、结构化输出、多候选、停止序列等不能由纯文本满足的请求继续正常转发。输出遵守客户端 token 上限，必要时使用相应协议的截断结束原因。

本地响应仍经过正常鉴权、权限、请求校验与用户限流，收费为零，响应头包含 `X-New-Api-Response-Source: local_response`。首次选路、重试和并发重选均按实际物理渠道检查。已预扣时退还未使用的额度；先前已发往其他上游的真实尝试仍按实际用量结算。

本地响应在周期卡单列次数，不增加上游成功率、首字、TPS、缓存命中率、调度或恢复成功次数。周期数据不保存请求正文和完整响应；策略变更保留管理审计。

## 周期口径

- 只为“禁止自动探测 + 已开启对应监测”的目标建桶。状态按物理渠道和模型统计，分组另匹配业务分组和配置模型。
- 以尝试完成时间归入 UTC Unix 时间对齐的半开区间，周期支持 30～86400 秒，包括 45 秒。排除实际探测、手动测试、模型检测、取消及未发往上游的本地错误。
- 首字和尝试耗时按有效样本取平均；TPS 使用总有效输出 token / 总有效生成秒数。缺值不补零，各指标分别计样本。
- 全禁探测分组按最终请求计算成功率；A 失败、B 成功算一次最终成功，各成员卡仍记录真实尝试。混合组并列显示探测结果和禁探测成员业务数据。
- 手动结果保留在实际检测历史。没有上游样本时，均值/成功率为空，不伪造 0% 或 100%。

例：两次请求首字 100/300 ms，输出 10/90 tokens，生成耗时 1/3 秒，均值应为首字 200 ms、TPS 25。

周期结果在结束后 48 小时内支持迟到修正，费用补结算不会重复增加样本。页面提供最多 30 天历史；小时汇总按周期结束时间归属，显示实际采样范围，不按比例拆分跨小时长周期。

模式切换后的首个周期可能不完整。数据库不可用或渠道已删除时跳过自动请求，已经开始的请求正常收尾。

数据缺口、积压和过期结果会使对应周期标为不完整。Redis 断开时不改发真实探测；已有的最后完整结果可以保留展示，但保留原时间并标记不可用。重启后 Redis 仍不可用时，无法提供该结果。

## 接口与容量

以下接口沿用渠道监控 Root 权限：

| 接口 | 用途 |
| --- | --- |
| `GET/PUT /api/channel_monitor/channel/:id/probe-policy` | 读取/保存策略；旧修订号返回 409 |
| `GET /api/channel_monitor/passive?scope=status&page=1` | scope 支持 status/group；可按 channel_id/group/model 过滤，每页 50 目标 |
| `GET /api/channel_monitor/passive/:target/history?days=1` | 1～30 天小时汇总，最多 720 行 |
| `GET /api/channel_monitor/passive/:target/versions` | 旧配置目标，有界读取最近 100 个索引项 |

PUT 字段：`auto_probe_disabled`、`small_input_response_enabled`、`small_input_threshold_tokens`、`small_input_response_text`、`probe_policy_revision`，均必填；响应另含 `probe_policy_updated_at`。缺少监控行的现有渠道默认关闭。复制渠道在创建事务内复制策略，不复制上游凭据或其他监控配置。

公开分组页面只暴露分组汇总，不暴露物理渠道、策略文本和成员清单。周期汇总不会再次作为智能调度样本。

最多支持 5000 个活动监测目标。没有业务样本的周期显示无数据，不伪造探测结果。

## 启用与关闭

多实例部署须所有请求节点都支持本策略。关闭小输入响应后恢复实际转发；关闭“禁止自动探测”时同时关闭小输入响应，并恢复按配置执行自动探测。已经发生的费用和待退额度继续结算。
