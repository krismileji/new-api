# 数据一致性边界

渠道监控同时维护 Redis 实时投影、数据库分钟聚合、日成本账本和智能调度状态。它们共享事件来源，但不共享同一个提交水位。页面、调度和清理必须按各自接口的语义读取，不能互相替代。

## 四条轨道

| 轨道 | 存储 | 用途 | 权威性 |
| --- | --- | --- | --- |
| Redis 实时投影 | Redis hashes / sorted sets | 管理页实时成功率、性能、今日卡片、调度样本窗口 | 低延迟读模型，不是账本 |
| 数据库分钟聚合 | `ChannelMonitorMinuteRouteMetric` 等 | 历史趋势、长期性能、调度历史窗口 | 分钟级历史，不是 Redis 副本 |
| 日成本账本 | `ChannelDailyCost` / `ChannelDailyAPIKeyCost` | 已结算/未解析人民币成本 | 金额事实源 |
| 调度状态 | `ChannelSmartScheduleRouteState` 等 | 参与、保护、主渠道、权重 | 控制面状态，受 revision 保护 |

## 时间窗口语义

- **实时窗口**：由 Redis 投影的 `window_start` / `window_end` / `data_cutoff_at` 描述。智能调度启用时，主表固定使用性能窗口 `1..43200` 分钟；关闭时允许手动 `1..1440` 分钟，默认 `15`。
- **分钟历史**：主节点在自然分钟结束 `1s` 后聚合消费日志。`ChannelMonitorAggregationState.completed_through` 是连续水位；迟到日志打 `ChannelMonitorDirtyMinute`，worker 以 `2min` lease 小批重算。
- **日成本**：按北京时间自然日记账。任务最终结算按原始日期和绝对目标修正，不把修正写到“今天”。
- **稳定性边界**：恢复保护只推进 `(渠道, 模型)` 观测起点。今日统计、按日趋势、余额和倍率不受该边界影响。

接口返回实际采用的分钟数和来源，页面前端以响应为准。

## Redis 与数据库不同步的可见表现

| 现象 | 含义 | 不应推断 |
| --- | --- | --- |
| `pending_count` / `consumer_lag_seconds` 增加 | 事件已 XADD，尚未消费 | 没有流量 |
| 实时页已更新、历史趋势稍后才更新 | 分钟 worker 还没到边界或 dirty minute 未修完 | Redis 投影是历史事实 |
| `realtime_degraded=true` | Redis 不可用、消费者停止、积压、发布失败、marker 释放失败或 Stream trim 失败 | 成本为 0 或渠道全失败 |
| 投影 `sample_limit_truncated=true` | 实时样本达到上限，旧样本被淘汰 | 窗口完整 |
| 日成本与实时今日成本不一致 | 实时投影不是账本；未解析、迟到结算、outbox 未完成都会造成差异 | 以实时金额扣用户额度 |

## 降级行为

Redis 故障或消费者停止时：

- 实时接口 metadata 置零并返回降级原因。
- 历史分钟表和日成本表继续提供只读查询。
- 智能调度必须把覆盖不足的窗口视为不可比较，而不是用残缺样本打分。
- 事件 writer 可把溢出事件写入 `ChannelMonitorEventOutbox` 后补发；成本路径可把事件直接写入成本 outbox。
- `CHANNEL_DAILY_COST_RELIABLE_OUTBOX=false` 只用于紧急回滚，不是默认一致性语义。

进程重启后：

- Redis runtime 以 `1s` 起步、最长 `30s` 退避重建消费组。
- 聚合器租约丢失后由其他节点/进程接管 pending。
- 分钟聚合从持久化水位追赶，启动尾巴为 `5` 分钟。
- 成本 outbox 由恢复任务继续处理，按事件 ID 幂等。

## 清理与窗口保护

清理任务按表分别保留：

- 路由分钟、首字分桶默认 `30` 天。
- API Key 分钟默认 `7` 天。
- 调度执行明细默认 `3` 天。
- 状态探测、分组监控历史默认 `7` 天。
- 倍率变更历史默认 `365` 天。
- 日成本默认 `30` 天。

清理会保护智能调度当前性能窗口需要的分钟数据。模型检测只清理 terminal/resolved 历史，`prepared` / `pending` 成本不会被直接删除。

默认开启清理，批次 `1000`，单次预算 `10s`，继续等待 `60s`，间隔 `24h`。超预算会留下进度，下一轮继续。

## 逻辑归组边界

逻辑归组只改变智能调度、状态探测和模型检测的共享身份。成本、余额、倍率、普通性能、日志、审计和并发租约仍按物理渠道记录，不生成逻辑组汇总。

## 权限与可见性

Root 管理接口可以看到降级原因、pending、消费者状态和完整失败分类。用户侧分组监控和用户侧日志不返回这些内部水位。实时管理接口统一禁止 HTTP 缓存。
