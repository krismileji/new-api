# 监控总览

Root 管理员在 `/channel-monitor` 查看渠道运行状态、上游配置、成本、性能与调度。页面数据以手动刷新为主，活动任务进度另行刷新；完整口径见[实时监控](realtime-monitoring.md)。

## 页面与入口

顶部展示渠道总数、今日成本、成功率和缓存指标。工具栏提供连接测试、任务历史、监控设置，以及上游账户、上游自动任务、共享请求与变量、共享限流组和 API Key 自动禁用等管理入口。

主区域包含渠道、分组、模型性能、状态监测、模型检测和智能调度视图。支持搜索、上游类型筛选、模型选择和渠道排序。人工顺序只影响页面，不改变路由优先级或权重；渠道排序也作为状态监测、模型检测卡片的主顺序。

手机和平板默认显示精简实时摘要，更多信息在“运行详情”中查看；宽表格和页签在各自容器内横向滚动。

## 渠道视图

渠道行展示启停、自动禁用原因、备注、原始/估算余额、今日人民币成本、成本倍率、上游分组、同步状态、本地关联分组和当前窗口性能。

并发与 RPM 统一显示“当前用量 / 上限”，不限时写“不限”；加入共享组后另显示组用量。RPM 来自最近 60 秒成功准入的上游尝试，不使用消费日志数量替代。

行操作可配置上游、余额策略、并发/RPM、探测策略、关联分组和调度参与，执行手动连接测试或查看历史。余额详情的已完成、在途预估和待确认部分见[余额预估](balance-estimation.md)；账户余额不得按渠道重复相加。

## 分组与模型

分组视图汇总本地售价倍率、实际及最终成功率、关联渠道成本倍率。可管理成员、修改倍率，或以参与渠道最高成本倍率乘分组系数同步；系数会持久化。

模型视图按选定模型展示各物理渠道的成本倍率、首字、TPS、成功率、样本和最后请求时间，适合启用调度前核对覆盖。

模型广场另有只读 `/group-monitor` 页面。它展示监控配置中的全部分类与分组，遵循 pricing 的公开/登录要求；不是按当前账号的模型调用权限过滤卡片。状态不可用的已配置分组仍保留展示，显示不授予调用权限。分类、开关、缓存率和业务周期监测见[分组监控](model-market-monitoring.md)。

## 分析与调度

成本和成功率卡片打开[分析与下钻](analytics.md)，支持日期筛选、趋势及渠道/用户/Key/模型层级。完整范围汇总不随页码变化；不同范围和数据来源不能直接互相对比。

智能调度视图按分组、模型列出已托管池、主备角色、有效优先级/权重、预计及实际流量分布、健康状态和执行记录。显示使用实际发布快照，详见[智能调度](smart-scheduling.md)。

主表在智能调度实际启用时使用设置的性能窗口，范围 `1..1440` 分钟；否则允许手动范围，默认 `15` 分钟。接口返回实际范围及来源，页面以响应为准。

稳定性恢复只推进渠道/模型的观测边界。主表与调度在边界后重新积累样本，缺样本显示 `-`；今日累计、历史明细、余额、倍率和并发保持各自口径。

## 刷新与异常

手动刷新重新获取公共摘要、当前视图、调度及已打开的分析/历史，同范围已有内容在加载时保留。已失活的查询不保留；主数据不因聚焦或重连自动刷新，探测/检测活动进度保留 1 秒刷新。

后台继续独立消费事件、保存日统计和记账。无样本、投影不可用、恢复中与历史缺口有不同含义；“今日诊断”重置也不会清掉当前故障。具体见[恢复与排障](recovery-troubleshooting.md)。
