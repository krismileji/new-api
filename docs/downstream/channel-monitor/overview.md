# 页面与功能

## 页面结构

页面顶部显示渠道总数、今日累计成本、今日成功率/缓存率、缓存写渠道数与请求数、已记录倍率数和本地分组数，并提供以下全局操作：

- 渠道连通性测试。
- 倍率更新和智能调度的任务记录。
- 渠道监控设置。
- 同时刷新概览、性能和成本摘要。

主区域包含“渠道”“分组”“模型”三个视图。页面支持搜索、上游类型筛选、模型选择、统计时间范围和渠道排序；人工顺序只影响渠道监控页面，不改变渠道优先级或路由策略。

点击成本或成功率/缓存率卡片可查看近 `7`、`30`、`90` 天柱状图和指定日期明细；成功率/缓存率弹窗通过页签同时提供缓存写渠道明细，日期下拉框与柱子点击使用同一选择状态。

## 渠道视图

每行渠道展示：

- 启用状态、系统自动禁用原因、渠道备注和 ID。
- 上游余额、余额更新时间和手动刷新入口。
- 今日人民币成本、数据是否完整及成本历史入口。
- 当前与上次成本倍率、上游分组及倍率更新时间。
- 最近倍率读取状态、错误和连续失败次数。
- 本地关联分组、分组倍率及同步系数。
- 平均首字时间、平均 TPS、成功率和样本数。
- 当前并发数与并发上限。
- 智能调度参与状态、最近得分和稳定性状态。

渠道级操作包括启用或禁用、单渠道连接测试、设置并发限制、更改关联分组、配置上游和查看倍率变更历史。已开启对应同步能力时，可直接刷新倍率或余额。

## 分组视图

分组视图汇总本地分组倍率、真实调用成功率、最终成功率以及关联渠道的成本倍率。Root 管理员可以：

- 管理分组关联渠道。
- 直接修改分组倍率。
- 取该组已启用且已有记录的渠道中最高成本倍率，再乘以分组系数同步分组倍率。
- 查看分组范围的成功率明细和各渠道拆分。

自动同步系数会持久化，下次定时策略计算继续使用。

## 模型视图

模型视图按所选模型对渠道排序，展示成本倍率、平均首字、平均 TPS、实际成功率、有效样本和最后请求时间。只显示支持该模型的渠道，适合在启用智能调度前检查数据覆盖。

## 成功率口径

“实际成功率”按真实上游调用统计，重试过程中的失败也算失败；“最终成功率”排除中间重试错误，表示请求最终对用户成功还是失败。

渠道明细还能按 HTTP 状态码、上游错误类型和错误码聚合失败，并显示脱敏的错误示例和最近发生时间。

## 数据刷新

概览、成本和性能使用独立查询。手动刷新会同时重新读取三类数据；单独修改倍率、分组、上游、调度或并发设置后，前端只使受影响的查询失效并重新获取。

性能和成功率是时间窗口统计，不是永久累计值。页面统计范围允许 `1` 到 `1440` 分钟，智能调度只使用固定的 `15`、`60`、`360` 或 `1440` 分钟窗口。
