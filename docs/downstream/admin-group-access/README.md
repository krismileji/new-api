# 管理员分组访问

管理员及更高角色可以使用 `GroupRatio` 中全部已配置的真实分组，不受普通用户 `UserUsableGroups` 映射限制。普通用户的分组规则保持不变。

`auto` 仍需按原有配置显式启用，不会因为管理员角色自动出现。角色感知的分组集合用于令牌固定分组校验、用户可选分组、模型列表、定价接口和中继路由。

请求仍必须经过原有鉴权，目标分组必须存在于当前 `GroupRatio` 配置；客户端不能自行提交角色值。

## 模型广场分组展示

`GET /api/pricing` 会按当前请求者的角色和可用分组过滤模型。模型至少命中一个可用分组（或使用 `all` 通配分组）时才会返回；返回模型中的 `enable_groups` 也会再次裁剪，只保留当前请求者可见的分组名称。

因此，匿名访问和普通用户在模型卡片、表格及详情页中不会看到未勾选“用户可选”的分组。管理员仍按本页前述规则看到 `GroupRatio` 中已配置的分组；`all` 仅作为通配标记保留，不会借此暴露模型关联的其他不可选分组。
